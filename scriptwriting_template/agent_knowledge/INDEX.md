# Agent knowledge

This directory is reserved for reusable preferences and lessons learned from
real scriptwriting sessions. The public template contains structure only; do
not add personal memories, private feedback, or real project notes here.

Use the subdirectories as follows:

- `writing/` — reusable pacing, narration, and scene-structure preferences
- `visuals/` — reusable composition and visual-pairing observations
- `models/` — model-selection lessons and tradeoffs
- `lessons/` — recurring feedback and outcomes

Knowledge is subordinate to current instructions and authoritative rules:

```text
current user instruction
    ↓
schema / hard validation rules
    ↓
SCRIPT_CONVENTIONS.md
    ↓
AGENT_SETUP.md and other setup documentation
    ↓
agent_knowledge/
```

Do not record every one-off instruction. Record a preference only when it is
confirmed or repeatedly demonstrated to be reusable. When a possible pattern
is not yet clear, ask before recording it. Learned knowledge must never
silently override a direct request or the actual script schema.
